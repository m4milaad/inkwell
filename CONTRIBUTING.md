# Contributing

1. Fork the repository and clone your fork.
2. Install dependencies and start the dev server:

   ```bash
   npm install
   npm run dev
   ```

3. Make your change on a new branch. Run `npm run format` and `npm test` before opening a pull request.
4. Open a pull request that explains what changed and why.

For larger changes, open an issue first so the approach can be agreed before you start.
